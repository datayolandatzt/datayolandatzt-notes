# datayolandatzt-notes

Data engineer · SQL and dbt · contributing on weekends

给自己省点事的小工具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/datayolandatzt-notes.git
cd datayolandatzt-notes
cargo build --release
```
